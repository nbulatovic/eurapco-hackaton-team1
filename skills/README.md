# Domain skills

Loading support is supplied in app/skills.py. These domain folders intentionally
contain no completed procedures. Write your Markdown skills, decide when/how to
load them into the agents, and preserve the documented business behavior. Framework and integration choices belong to your team.

Start from [TEMPLATE.md](TEMPLATE.md): copy it to `skills/<agent>/<name>.md`. The runtime appends
every skill of the handling agent to that agent's system prompt.
